# Original Olist data

Download the [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
and use the five unchanged CSV files listed in [source_manifest.json](../source_manifest.json).

For local validation, place the CSVs here. For Databricks execution, upload them
directly to the managed volume created by `00_setup`, without extra subfolders.
The code repository and code archive exclude raw CSVs.
